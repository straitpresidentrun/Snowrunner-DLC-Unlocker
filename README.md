# SnowRunner DLC Unlocker: Automatic DLC Unlocker Tool

An all-in one tool that automatically unlocks, downloads and activates DLCs in **SnowRunner***, both in modded and unmodded versions of the game, single and multiplayer.

# 🖥️ System Requirements

Before running the application, ensure you have:

- A legitimate copy of **SnowRunner**
- Steam or Epic Games Store installation
- Updated version of the game
- Microsoft .NET 7 Runtime (or newer)
- Internet connection
- WinRAR or 7-Zip

# ⚡ Installation

## 1. Download

Download the latest version from the **Releases** page.

## 2. Extract

Extract the archive to any folder.

## 3. Launch

Run the application. Administrator privileges may be required on some systems.

## 4. Locate Your Game

Select your SnowRunner installation folder.

## 5. Scan

Click **Scan** to detect installed game content and available DLC.

## 6. Play

Launch SnowRunner directly from the application.

# 🔧 Troubleshooting

| Problem | Solution |
|----------|----------|
| DLC not detected | Verify game files through Steam or Epic Games Launcher |
| Missing content | Confirm the DLC is installed through your platform |
| Application won't start | Install the latest .NET Runtime |
| Scan returns no results | Check that the correct game directory is selected |
| Unexpected behavior | Restart the application and scan again |

---

# 💡 Tips

- Keep SnowRunner updated to the latest version.
- Verify game files after installing new DLC.
- Run another scan whenever additional content is installed.
- Use official game installations for the best compatibility.
- Back up any custom configuration files before making changes.
